# 设计意图卡（可跳过）

> 填多少算多少；不知道的写「未知」。整份跳过时，由 agent 在最后一节写推断结果。
> 本卡用于帮助判断「板子应该做什么」，不是放行依据。

## 1. 基本信息

- 工程名 / 版本 / 日期：
- 板子用途（一句话）：
- 板型档位（A 简单数字/电源、B MCU/混合、C 高速/射频/精密、D 高压/大功率/隔离）：
- 审核请求人 / 资料提供人：

## 2. 电源

- 输入来源与范围：
- 各路电压 / 最大电流：
- 上下电顺序 / 电池或适配器：
- 已知电源风险：

## 3. 接口

- 每个连接器：对端设备、线序、电平、速率、是否需要隔离
- 外部暴露接口 / 可能接触人体的接口：

## 4. 关键器件

- MCU / ADC / 运放 / 电源芯片 / 连接器 / 保护器件的 MPN
- 是否有指定替代料 / DNP / 装配变体：

## 5. 环境、标准、制造

- 温度、湿度、振动、防护、安规 / 隔离要求：
- EMC 目标市场 / 标准 / 是否预测试：
- 板厂、层数、板厚、阻抗、装配面、批量：
- 通用加工建议关注点（铜厚/载流温升、板厚/刚度、层叠/阻抗、孔槽/表面处理等）：

## 6. 本次关注点

- 最担心哪类问题（电源 / 接口 / 时序 / EMC / 几何 / BOM）：
- 哪些已知风险不用重复报：
- 哪些模块本次不审：

- 推断出的电源树 / 接口 / 关键器件：
- 置信度（高 / 中 / 低）：
- 待人工确认的点：
