## 读数

- 原理图：127 元件 / 469 引脚 / 98 网；引脚无网 40 个，其中 33 个有 NC 标记。
- PCB：127 元件 / 501 焊盘 / 98 网；2 层铜；板框 45.0 × 70.0 mm。
- 原理图 vs PCB（均 API 原生）：469/469 引脚、98/98 网，**0 差异**。
- API vs 离线 `extract.py`：98 个多引脚网的分组**完全一致**；40 个未连引脚在离线侧被命名为单点本地网，属命名差异，不是连接差异。
- 板框：离线 `board_size` 修复后与 API 一致（45.0 × 70.0 mm）。
