## 4. 错误与规避

| 错误 | 原因 | 处理 |
|---|---|---|
| 单脚全量快照「EDA window disconnected」 | 单次执行过长/消息过大 | 拆成 PCB + 3 页；每页元件分 10 个一批 |
| `EPCB_LayerId is not defined` | 执行上下文未暴露枚举 | 板框层用字面量 `11` |
| 焊线取点返回空 | 方法名用错 | `getState_Polyline()` → `getState_Line()` |
| 文本取值为空 | 方法名用错 | `getState_Text()` → `getState_Content()` |
| `KeyError: 'designator'` | 网络标志元件无位号 | 改 `c.get('designator')` |
| `pcb_Net.getAllNetsName()` 返回 `None` | 当前文档是原理图页 | 先激活 PCB 文档 |
| `pcb_Net.getNetlist('EasyEDA')` 超时 | CLI exec 超时未随 `--timeout` 提高 | 放弃该调用；改用已导出的两侧网表比对 |
| WebFetch 全部被拦 | 环境不允许直接取 PDF | 手册事实降级为「检索引述」，报告中标注 |
