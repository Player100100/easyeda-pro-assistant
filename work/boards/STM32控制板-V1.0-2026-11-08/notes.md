# 过程记录 — STM32控制板 / 2026-11-08

## 1. 取证方式

1. 启动 bridge（`python src/eda.py up`），确认 EDA 窗口连接（`/eda-windows`，单窗口自动选中）。
2. 先尝试单脚全量快照（PCB + 3 页原理图 + 网表）——超时/窗口断开，改为分片：
   - `pcb.js`：PCB 图元、焊盘、过孔、铺铜、板框、层、网、DRC、规则。
   - `sch_page.tpl.js`：按页生成 `sch_interface.js` / `sch_power.js` / `sch_mcu.js`，每页分 10 个元件一批。
   - `texts.js`：读三页文本对象，确认网络标签/注释（用于判 CN2/CN3 方向、电源页功能块）。
3. 导出 `sch.net` / `pcb.net`，逐引脚比对（79 元件、306 引脚、69 网）。
4. 器件手册事实由 `researcher` agent 检索；WebFetch 被拦，全部为搜索结果引述，未直接打开 PDF。报告中统一标「手册引述（检索）」。

## 2. 关键判断记录

| 判断 | 依据 | 结论 |
|---|---|---|
| U1 35/47 与 36/48 是电源脚反接 | 符号 pinName = VSS_2/VDD_2/VSS_3/VDD_3；STM32F103 LQFP48 引脚表 | 确认 F-001（S0） |
| CN2/CN3 是输出 | 电源页文本「XT30输出」「24V输出」「12V输出」；U9/U10 在 +24V/12V 与连接器之间 | **仅为推断**，F-003 记待复核（若为输入则方向正确） |
| U5 方向正确 | U5.2(A)=CN1 输入侧，U5.1(C)=+24V | 排除误报 |
| U4 EN 接 GND 正确 | XL1509 EN 低有效 | 排除误报 |
| U2 ON/OFF 接 GND 正确 | LM2596 ON/OFF 低=开 | 排除误报 |
| U8 pin15 悬空正确 | CH340C R232 悬空 = TTL 模式 | 排除误报 |
| USB-C 为 sink | R3/R4 5.1K 下拉到 GND（CC1/CC2） | 支撑 F-004 的违规判断 |
| U10 由 12V 供电 | U10.1 网名 VCC+12V（早前误记为 +24V） | 撤回 D3 TVS 选型候选 |
| 127 个原理图图元 vs 79 个网表元件 | 35 GND 符号 + 3 Power-5V + 7 Short-Symbol + 3 图框 = 48 非网表图元 | 数据一致，无遗漏 |
| 7 个 Short-Symbol 是逻辑短接 | 合并 7 组别名；两侧网表均无别名网残留 | B-07 PASS |
| DRC Netlist Error 与导出网表 0 差异冲突 | `drc_pcb_out.json` vs `sch.net`/`pcb.net` | 保留 F-014 待复核，不自行判定哪侧过期 |
| X1/X2 CL 值 | 来自 BOM 的 Load Capacitance 字段（9pF / 12.5pF），非仅经销商数据 | F-007/F-008 证据升级 |
| PTC 保持电流 | BOM Hold Current=50mA / Trip Current=150mA | F-006 证据升级 |
