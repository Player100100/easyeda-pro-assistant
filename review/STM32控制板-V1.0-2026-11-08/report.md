# STM32控制板 首轮只读审核（EasyEDA Pro API 数据）

**日期**：2026-11-08　**项目**：`projects/epro2-辅助绘制及审核`　**工程**：`何俊熙` / `Board1`
**数据来源**：嘉立创EDA专业版 3.2.149.88089769，API bridge 只读采集；原理图/PCB 导出网表（EasyEDA JSON v2.0.0）+ 焊盘/走线/过孔/铺铜/板框/DRC/规则 + 三页原理图对象 + BOM 字段。
**范围**：原理图 + PCB + BOM。**未取得 `.epro2` 离线包**，离线网表 vs API 的 A-03 对账未做；A-04（焊盘坐标对账）同样缺离线输入。
**板型档位**：B（MCU/混合信号），2 层，70.0 × 100.0 mm。

## 结论

本轮发现 **2 项已确认的电气连接错误**（1 项 S0、1 项 S1），另有 **1 项 S1 在「CN2/CN3 为输出」的前提下高度可疑**。F-001/F-002 在网表和 PCB 焊盘网名两处一致，不依赖设计意图即可判定；**修正前不具备投板条件**：

1. **F-001（S0，已确认）U1 电源脚成对反接**：U1.35/47（VSS_2/VSS_3）接 VCC+3.3V，U1.36/48（VDD_2/VDD_3）接 GND。3.3V 与 GND 在芯片内部电源环上被直接短接，上电可能损坏 U1 并拖垮 3.3V 轨。结论依赖符号引脚名（C-10.2 未核厂商图）。
2. **F-002（S1，已确认）复位按键接到 3.3V**：SW1 的 3/4 脚接 VCC+3.3V，按下时把 NRST 拉高而不是拉低，复位功能失效。
3. **F-003（S1，待复核）24V/12V 输出二极管方向**：U9/U10 阴极接电源、阳极接输出连接器。**若 CN2/CN3 确为输出**，两个输出口在负载下被反偏截止；若两口实为输入，现方向反而是正确的防反接。CN2/CN3 的角色目前只有丝印文本「24V输出」「12V输出」作依据，需用户确认。

另有 **6 项 S1 待复核**：F-003、F-004（USB-C 与板载 5V 直连）、F-005（AMS1117 输出无储能电容）、F-006（5V PTC 保持电流偏小）、F-010（DBUS 基极无限流）、F-014（DRC 网表冲突）。其余为 8 项 S2、3 项 S3。

数据一致性方面结果良好：两侧网表 **79 个元件 / 306 个引脚 / 69 个网，0 处差异**；306 个原理图引脚与 306 个 PCB 焊盘一一对应；无单脚网。PCB DRC 仅有 1 条 "Netlist Error"，与导出网表的 0 差异冲突，单独列为待复核（F-014）。

**本报告只列问题、覆盖率和无法判定项，不给放行结论。**

## 背景

- 用户要求在嘉立创EDA专业版中审核当前打开的板子，未提供设计意图卡。
- 板子用途、负载、环境均按网表/丝印推断（`intent.md`，标 `inferred`）：STM32F103C8T6 最小系统 + 24V→12V→5V→3.3V 多级电源 + USB 转串口 / DBUS / SWD 扩展。
- 审核口径按项目 `CLAUDE.md`（2026-11-06 确认）：原理图 + PCB + BOM；只读 API；报告只列问题/覆盖/无法判定项。
- 判据按 `docs/review-criteria-v2.md`：`PASS` 需「要求明确 + 输入完整」，`FAIL` 需可复现证据，不满足则 `REVIEW`；未执行一律 `NOT_CHECKED`，不计入通过。

## 方法

1. **取数**：bridge 连接运行中的 EDA 客户端，分片采集 PCB 与三页原理图（单次全量快照会超时），导出 `sch.net` / `pcb.net`，另读三页文本对象确认网络标签与功能块注释。
2. **一致性**：逐引脚比对两侧网表；核对位号集合、封装名、引脚数/焊盘数；解释 127 个原理图图元 vs 79 个网表元件（48 个 GND/电源/短接/图框符号）。
3. **电气**：按 B → C → D → F 顺序逐项核电源脚、上下拉、反馈、时钟、保护、接口电平；手册事实由检索获得。
4. **几何**：读 DRC、规则、走线宽度、过孔、板框、铺铜；铜到边/孔到边按焊盘与板框坐标计算。
5. **封装**：79 个实例逐一绑定 MPN/LCSP/封装名，生成 `footprint-expectations.json`。
6. **复核**：S0/S1 与覆盖率交独立 `reviewer` agent 复核（见文末）。

**手册引用限制**：本轮 WebFetch 对所有域名被拦，未能直接打开 PDF。器件手册事实全部来自搜索结果引述，报告中标「手册引述（检索）」；条款号与数值需人工回查原文后才能作为最终依据。BOM 字段（Load Capacitance、Hold/Trip Current、Rated current）属于工程内明确数据，不受此限制。

## 结论与下一步

1. **先修 F-001/F-002**，这两项不依赖意图，属于确定的连接错误。F-001 修正前不要给板子上电；若已经上过电，需单独确认 U1 是否损坏。同时确认 U1 符号 35/36/47/48 的引脚名与厂商图一致（C-10.2 未核）。
2. **确认 CN2/CN3 的角色**（F-003）：若为输出，U9/U10 需调换 A/C；若为输入，当前方向正确，F-003 可关闭。
3. **补齐 F-004 的使用场景**：USB-C 只受电，还是也要对外供电。两种答案对应不同的修法（ORing 二极管/理想二极管/负载开关，或明确禁止同时接入）。
4. **电源与时钟外围一起改**：F-005（AMS1117 输出加 10–22µF）、F-006（按实测 5V 电流换 PTC）、F-007/F-008（按晶体 CL 重算负载电容）。
5. **输出能力要按电感重算**（F-019）：L1/L2 只有 1.1A/1.35A，若需要 2A/3A 输出，电感和走线（F-016）都要换。给出 24V/12V/5V 各路最大电流后，按 IPC-2221 或板厂建议统一核算。
6. **USB 数据线补 22Ω**（F-012）：CH340 的 D+/D− 串阻，和 ESD 一起评估。
7. **BOM 补全**（F-013）：49 个元件补 MPN，核对 SS54 的 SMA/DO-214 描述与 USB1 的实际厂商。
8. **F-014**：在客户端执行 Import Changes 前先看差异预览，确认哪一侧过期，再重跑 DRC。
9. **下一轮取证**：导出 Gerber/钻孔（F-04）、取得关键器件厂商图纸（C-10.2/4）、在客户端读取 ERC 明细（F-015）。
