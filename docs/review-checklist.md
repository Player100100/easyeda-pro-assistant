# 审核清单（执行项索引 v1，受 v2 判据约束）

**日期**：2026-11-06 　**配套**：`docs/review-method.md`

> **判据校订**：执行前必须同时遵循 [`review-criteria-v2.md`](review-criteria-v2.md)。与 v2 冲突的硬性阈值/集合判据不作为 PASS/FAIL；特别是 A-02、A-05、B-01、B-02、B-07、D-02、D-04、E-01、E-02、E-03、E-06、G-01。当前离线 PCB 检查脚本尚不能支撑 D-04 或完整 DRC 通过结论。

## 用法

1. 先定板型档位（A/B/C/D，见 `review-method.md` §3.1），再决定 E/G 类查到哪。档位写进报告头。
2. 先查 A 类（数据一致性）。数据不一致时，阻断依赖该数据的结论，并记录影响范围；其他可信输入支持的检查可继续。
3. 按 B → D → F → C → E/G 的顺序跑；每项记录 `分母 / 已覆盖 / 未覆盖原因`。
4. 每条 finding 必须带定位串和证据引用；严重度/状态/依据按 `review-method.md` §5。
5. **没跑 ≠ 通过**。未执行的检查写 `NOT_CHECKED`，并写清楚缺什么。
6. 语义项按 `review-method.md` §4 步骤 4 分给 agent（电源 / 接口 / 时钟复位 / PCB 几何 / BOM / 汇总），再由独立 reviewer agent 复核。

| C-05 | 保护 | 防反接、TVS、保险丝、ESD + 环境/系统防护 | 按暴露场景/故障条件核是否需要以及保护额定值和路径 | 依证据定级 |

**C-10 执行方式（2026-11-08 新增）**：见 [封装匹配审核](footprint-review.md)。每个在审 PCB 元件都纳入型号/封装绑定与实例映射核对；常规官方封装可引用满足复用条件的历史证据，不做无依据的重复量测。连接器、极性器件、裸露焊盘/特殊封装、关键器件、自建/修改/来源不明或更换过的封装重点复核。未执行的尺寸/实物脚位子项标 `NOT_CHECKED`，不能因官方来源、双网表一致或 DRC 无报项直接标 `PASS`。A-07 负责脚号映射，C-09 负责装配变体一致性，C-10 复用其证据并核对厂商定义；同一问题共用 finding ID。

**C-08 的实例**：Candis FPC1 的 22 个可比引脚满足 `pcb_pad = 25 − sch_pin`（原理图引脚号与 PCB 焊盘号反序）。这是「待人工核对」的候选，必须对照 FPC 座子图纸确认，不能直接判错。

## 4. D 类：PCB 几何与 DRC

| ID | 检查项 | 数据来源 | 判定标准 | 严重度 | 自动化 |
|---|---|---|---|---|---|
| D-01 | API DRC + 原理图 ERC | 对应文档的 DRC/ERC 调用及规则快照 | 确认启用规则/范围后保存原始结果；逐项分析 error/warn，空数组只证明该次检查未报项 | 依后果定级 | ◐ 可取数，规则/归因需复核 |
| D-02 | 几何 DRC 复算 | `pcb.json` + `RULE` + API `getCurrentRuleConfiguration()` | 线宽/间距/孔径/环宽/铜到边 ≥ 规则值；分别记录 API `unit` 与离线 `RULE.unit`，冲突时以可信接口/人工确认值为准，不能按数值像 mil 反推；严重度按实际影响 | 依后果定级 | ◐ |
| D-03 | 板边/元件间距 | `outline` + 元件/焊盘 | 铜/元件到板边 ≥ 规则或厂能力 | S1 | ◐ |
| D-04 | 布线连通性与短路 | pads/tracks/vias/实际填充铜 + 网表 | 同网满足连接需求，异网无未授权接触；含实际层跨越/填充/几何 | 依影响定级 | ◐ 当前脚本仅候选，见 v2 |
| D-05 | 过孔/钻孔 | `vias` + 厂能力 | 直径/孔/环宽/盲埋 ≥ 厂能力；与规则一致 | S0 | ✅ |
| D-06 | 层/叠层 | `layers` / `stackup` | 铜层数、叠层参数、阻抗可算 | S1 | ◐/✖ |
| D-07 | 铺铜 | `POUR` / `POURED` | 无孤岛/死铜；热焊盘正确；网归属正确 | S1 | ◐ |
| D-08 | 丝印/重叠 | API `pcb_PrimitiveAttribute.getAll()`（位号 `ValueVisible`）+ `pcb_PrimitiveString`；几何 + 3D | 位号可见且在板内；丝印不压焊盘；元件不干涉；极性标识清楚 | S2 | ◐ |
| D-09 | 板框/安装孔/限高 | API `pcb_PrimitivePolyline.getAll(undefined, 11)` + `pcb_PrimitivePad.getAll(11)`；结构要求 | 闭合、尺寸、孔位、限高符合结构 | S1 | ◐ |
| D-10 | 测试点/基准点 | 设计意图 | 按需；关键电源/调试口有测试点 | S3 | ○ |

**D-04 的做法与坑**（2026-11-06 原型验证）：
- 焊盘必须按**形状/宽高/层**参与判定（旋转矩形/椭圆），不能只用中心距；用中心距会把「走线终点落在焊盘边缘」误判为断路。
- 必须做**layer-aware**：顶层走线不能连到底层走线；只有过孔/多层焊盘（`layer=12`）能跨层。
- **铺铜必须参与**：GND/AGND 这类网靠铺铜连通；只算走线会把一个网报成大量假连通分量。但 `POUR.path` 的坐标系尚未核实（样本矩形 `y` 为正、板框 `y` 为负），铺铜参与方式需先校准，否则宁可不开放这类网。
- 底层元件的焊盘坐标先过 A-04；未对账的元件，D-04 只能给候选。

## 7. G 类：仿真（按需触发）

> **触发条件（四条同时满足才跑）**：① 结论依赖 datasheet 没给出的数；② 有可信模型或可验证等效参数；③ 结果会改变审核意见或设计取舍；④ 跑前能写清通过判据。不满足就写「不需要仿真」及理由，不硬跑。

| ID | 检查项 | 工具 | 输入 | 判定 |
|---|---|---|---|---|
| G-01 | 电源环路/纹波/瞬态 | LTspice/ngspice | 稳压器型号、外围值、输入/负载/容差/模型 | 按器件手册/项目要求的稳定性、纹波及瞬态指标判定；45° 不是通用门限 |
| G-02 | 分压/基准/滤波/保护/时序 | LTspice/ngspice | 电路参数、容差 | 阈值/截止/钳位/延时符合意图 |
| G-03 | 信号完整性 | — | 叠层 + IBIS | 数据不足 → `NOT_CHECKED`（样本叠层参数为 0） |

**不适用**：网表/连通性/封装/BOM/DRC；无叠层无 IBIS 的 SI；EMC 合规；替代 datasheet 核对。

**记录要求**：模型来源与版本、测试台、激励、`.MEAS`/测量点、单位、corner/温度（跑了的才写）；deck 与结果放 `outputs/audit/<工程>/<版本>/sim/`，报告引用的关键文件复制到 `review/<工程>-<版本>-<日期>/evidence/`。报告写「判据 → 仿真值 → 通过/不通过/无法判定」，没跑过的不写数值。

## 8. MVP 首批实现（建议）

按「能最快形成可信结论」排序：

1. **A-01 / A-02 / A-03 / A-05** — 数据可信度；A-02 已补共有引脚自动网拓扑，仍需解释未覆盖对象后才声明覆盖范围。
2. **A-04** — 离线 vs API 焊盘坐标对账；这是几何结论的前置，未校准元件的几何结果只能是候选。
3. **B-01** — 未连接脚意图逐脚核验（API NC 标记 + 手册 + PCB 映射；不要求集合相等）。
4. **B-02 / B-03 / B-07** — 单脚网、电源脚、短接语义。
5. **D-01 / D-05** — DRC 汇总、过孔；**F-01** 仅在项目指定板厂后接入。
6. **D-04** — 已区分同网连接/异网候选，继续补具体定位、层跨越和几何模型；`--with-poured` 仅导出数据，不代表已有正确铺铜算法。
7. **C-10（局部自动比对 + 人工/agent 复核）** — 用 `src/check_footprints.py` 对提取结果和经审核的期望清单进行比对，输出 JSON、Markdown 和覆盖率；人工补核功能、极性/观察面、未覆盖的尺寸/装配条件，填写 `footprint-review.md` 记录表。自动通过不等于完整子项通过；缺少封装证据只影响相关结论，不阻断其他检查。

完成标志：一条命令生成 `audit.json`，报告能列出 `PASS / FAIL / REVIEW / NOT_CHECKED / NOT_APPLICABLE`（中文映射见 `review-method.md` §5.2）及覆盖率。

## 9. 豁免与白名单

- **单脚网白名单**：测试点、预留焊盘、天线、屏蔽脚；每条写对象、理由、批准人。
- **NC 白名单**：datasheet 明确「不用接」的脚；必须引用页码。
- **S1 已知风险**：设计负责人确认接受时，记录影响范围与复审日期。
- **S0 不允许 AI 自行关闭**；只能由人明确接受风险，并在报告里标红。
- **豁免不删除 finding**。检查结果、风险接受记录分开写；本项目不据此给放行结论。

## 10. 设计意图卡（审核前必须填）

1. **电源**：输入范围/来源；各路电压、最大电流、上下电顺序；电池/适配器。
2. **接口**：每个连接器的对端设备、线序、电平、速率、是否需要隔离。
3. **关键器件**：MCU/ADC/运放/电源芯片/连接器的 MPN + datasheet。
4. **环境**：温度、湿度、振动、防护、安规/隔离要求。
5. **EMC**：目标市场/标准（FCC/CISPR/CE）、有没有预测试计划。
6. **制造**：板厂、层数、板厚、阻抗要求、装配面、预算/批量。
7. **机械**：板框尺寸、安装孔、限高、连接器位置。
8. **版本**：原理图/PCB/BOM 版本号；本版改了什么；已知问题。
9. **本次关注点**：最担心哪类问题（电源/接口/时序/EMC）；哪些已知风险不用重复报。
10. **审核边界**：哪些模块本次不审；谁提供对端/结构资料。
