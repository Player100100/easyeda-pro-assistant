# C-11 关键网络供电与电荷预算审核

2026-11-10 纳入审核规范。第一版覆盖关键电源轨，在 C-01 电源树、C-02 去耦后执行；当前由 agent/人工依据手册、计算和必要仿真完成，尚无自动预算检查器。新增规范不表示历史板卡已补审。状态与证据要求沿用 [v2 判据](review-criteria-v2.md)。

## 1. 范围与关联检查

目标是核实指定工况下，电源与储能电容能否使关键负载引脚的电压保持在要求范围内。优先覆盖 MCU/FPGA/射频供电、精密模拟供电、大脉冲负载、外设启动和多负载共用电源。先列所有电源轨，再注明关键轨选择理由及排除范围；未知关键性保留待确认。

| 检查 | 为 C-11 提供的依据或承担的工作 |
|---|---|
| C-01 电源树 | 来源、上下游变换、负载归属、使能、反馈、启动顺序 |
| C-02 去耦 | 实装电容、有效容量、耐压/ESR与器件要求 |
| C-11 预算 | 汇总同一工况的需求与供给，计算余量和电压边界 |
| E-02 / PCB 审核 | 局部供电/回流、隔离器件及路径阻抗证据；离线几何须满足 A-04 校准条件 |
| G-01 仿真 | 简化计算不能解决的动态响应、稳定性或纹波问题，按现有四条触发条件执行 |

MOSFET 栅极、ADC 采样和总线充电依其器件模型在 C-07/C-03/C-06 核验；本版不将其计为已覆盖的电源轨预算。跨项共用 finding ID，注明关联检查，避免重复报同一个问题。

## 2. 输入与供电边界

每条记录定位到「工程版本 / PCB / 电源轨或局部支路 / 负载位号及电源、地引脚 / 工况」。参数均写数值、单位、来源文件及页码/表号、适用条件；区分厂商保证值、典型值、实测值和假设，典型曲线不自动视为最坏界限。

- **工况**：输入电压与源阻抗、环境温度/散热、装配变体、固件版本及配置、持续运行/启动/休眠唤醒/突发/负载释放；记录负载的并发或互斥关系与证据。无互斥证据时可作并发筛查，但须标假设；不能把未知负载记成零。
- **需求**：逐负载持续/峰值电流、峰值是否为总值或增量、上升/下降时间、脉宽、周期/占空比、浪涌、允许最低/最高电压和纹波。测量点是负载引脚相对其本地地，电压限值取推荐工作范围及项目要求。
- **电源**：完整型号、输入范围、压差/效率、温度与散热降额、持续输出能力、限流/折返/打嗝、软启动、反馈与动态响应证据。不能直接拿最大额定值或开关峰值限流当连续输出能力；不能用静态额定电流代替瞬时供给电流。
- **电容**：位号、型号、装配状态、标称容值、容差、实际偏压/温度/老化下的有效容量或曲线、相关频率下 ESR/ESL、纹波能力、初始电压。未经依据不得统一乘某个降额系数。
- **路径**：电源与回流的走线/平面/过孔、连接器、线缆、磁珠、电阻和负载开关；记录电阻、电感或阻抗模型及来源。相同网名不代表瞬态阻抗可忽略；跨磁珠、开关或较大阻抗的储能不能直接并入本地电容。

计算前明确边界：`I_source(t)` 是穿过该边界进入本地节点的电流，`I_load(t)` 是节点的负载电流，`C_eff` 是边界内独立计入的电容。若电源实测/模型响应已包含某组输出电容，不得再次把该电容的放电算作额外供给；上游和本地储能的归属必须一致。

## 3. 四个子项与计算方法

### C-11.1 持续供电与上游预算

按有依据的并发工况汇总持续电流，报告 `I_margin = I_available − ΣI_load`。`I_available` 使用该输入/温度/散热条件下可用能力，并核路径载流与压降。上游预算沿电源树逐级折算：DC/DC 按输出功率和相应工况效率折算输入功率，并按手册定义处理静态损耗；LDO 核输入电流、压差与耗散功率。不同电压轨的电流不能直接相加，同一负载不能沿树重复计入。

平均电流只用于适当的持续/热预算；峰值、启动和限流动作另核。余量要求来自项目或器件，不统一设置 20% 等门槛。

### C-11.2 瞬态电荷与有效容量

在电流缺口为正的单次放电区间 `[t0, t1]`，所需电荷为：

```text
Q_deficit = ∫[t0,t1] (I_load(t) − I_source(t)) dt
Q_cap ≈ C_eff × ΔV_C_budget
Q_margin = Q_cap − Q_deficit
```

电流用 A、时间用 s、电荷用 C、电容用 F、电压用 V。`ΔV_C_budget` 是扣除电源初始偏差、纹波和路径/ESR/ESL 等占用后，留给电容本体放电的压降预算；需说明各项是否重叠，不能重复扣减已含在波形中的项。没有正的剩余预算时，增加电容不能解决全部问题。

`C_eff × ΔV` 只适用于所用容量在该电压区间可近似为常量，或采用有依据的容量下界；容量随电压显著变化时，用 `Q_cap = ∫[V_low,V_high] C(V) dV`。在电压/温度等范围内无有效容量依据，不能把标称值当通过依据。

响应时间须来自相符工况的手册、可信模型或实测；不能用 `1/开关频率` 代替环路响应时间。多峰、重复脉冲或部分充电情况按 C-11.4 的累计电荷轨迹处理。

### C-11.3 路径压降与负载引脚电压

在适用的集中参数模型内，分别核电容压降、`I_C × ESR`、供回电路径的 `I_path × R_path`，以及相关支路的 `L × di/dt`。各支路使用实际对应电流及变化率；总压降应按同一时间轴求和，或使用说明保守性的上界，不能把不同时间的极值和重复建模的寄生项机械相加。

验证负载引脚 `V_min`、`V_max`、纹波与项目/器件要求，包含负载释放后的过冲。电荷足够仅支持 C-11.2，不证明电容能在目标时间尺度把电荷送达负载。高速分布效应、反谐振或缺少可信路径参数时，相关结论保留缺口，按需转 G-01 或实测。

### C-11.4 周期恢复与启动

对包含供给与消耗的完整时序计算：

```text
q(t) = q(t0) + ∫[t0,t] (I_source(τ) − I_load(τ)) dτ
```

检查每次脉冲开始前的实际电压、最低储能、恢复时间，以及重复工作是否出现逐周期跌落。恢复电流受电源响应、限流及负载剩余电流约束，不能假设瞬间回满；周期净电荷不亏也不能替代周期内最低电压检查。

核上电时给输出电容充电与负载启动的总需求、软启动、限流和复位/使能门限。负载移除后核过冲与电源吸收/泄放能力。不能默认初始电容满电，也不能把单次脉冲通过扩展成无限重复通过。

## 4. 执行、判定与报告

1. 用已核对网表建立电源轨/负载清单，选择关键轨并记录范围；依 C-01/C-02 确认源和储能。
2. 从意图卡、手册、固件配置或实测建立工况表与参数证据。推断的工况标 `inferred`，列待确认项；缺意图不阻断其他有依据的检查。
3. 按 C-11.1～C-11.4 记录计算式、输入、结果、适用边界和余量；使用 [板卡记录模板](../work/boards/_template/power-charge-budget.md)。
4. 简化计算不足时按 [审核流程 §4.1](review-method.md) 决定是否进入 G-01；缺模型导致无法判定写 `NOT_CHECKED`，不能写成不需要检查。仿真保留模型版本、激励、测量点、角落条件和结果。
5. 由独立 reviewer 复核重要问题、边界内储能重复计算、并发关系、上下游折算与遗漏工况。报告只列问题、覆盖率和无法判定项。

| 状态 | 使用条件 |
|---|---|
| PASS | 该子项的要求、工况和证据完整；计算/模型或有效保守界限支持在所列范围满足要求 |
| FAIL | 有依据的实际工况/模型或界限足以证明违反明确要求；标出负载引脚、工况和后果 |
| REVIEW | 工程推断、待确认假设或保守筛查发现疑点；悲观估算不满足并不自动证明实际失败 |
| NOT_CHECKED | 未执行或缺负载时序、响应、有效容量、路径参数等必要依据；列补证项 |
| NOT_APPLICABLE | 该子项确实不适用并有理由；缺资料、未检查或低风险不能充作不适用 |

按 C-11.1～C-11.4 分别统计「关键电源轨/局部支路 × 工况」，逐一列已执行、可判定、未检查和不适用；关键轨数、负载清单或工况范围未知时注明分母未知，不填 0 或 100%。部分子项 PASS 不升级为整网通过；有证据的 FAIL 与其他子项缺口同时保留。
