# 通用加工参数建议

## 目的与边界

本文件定义在**未指定板厂**时，如何根据电气、热、机械和可靠性需求输出 PCB 加工参数建议。它是设计输入建议，不是某家板厂的能力承诺，也不是制造放行结论。

建议必须绑定一个工况、假设或需求来源。缺少关键输入时可以给出“需要补充什么”的建议，但不能把常见值写成必然合适的值。板厂确定后，仍须用该板厂当前能力、报价工艺和 CAM 结果重新核对。

## 建议的输出格式

每条建议至少包含：

| 字段 | 要求 |
|---|---|
| 参数 | 例如外层铜厚、板厚、层数、最小线宽、最小孔径 |
| 当前值 | 从 PCB/API/制造文件读取；未知写 `UNKNOWN` |
| 建议值或范围 | 写明是起始建议、设计目标还是计算结果 |
| 适用条件 | 电流、允许温升、耐压、频率、板框、连接器和环境等 |
| 依据 | 器件手册、IPC/IEC 条款、计算式、项目需求或工程假设 |
| 状态 | `RECOMMEND`、`REVIEW`、`NOT_CHECKED`；不写板厂 `PASS/FAIL` |
| 复核条件 | 指定板厂、补充工况、完成热/压降/耐压计算或取得 CAM 反馈 |

建议值与当前值不同，只表示值得评估修改；只有明确违反已知设计要求时，才形成审核 finding。

## 参数建议原则

### 1. 铜厚、载流和压降

- 先按每条电源/大电流网络的连续电流、峰值电流、允许温升、允许压降、走线长度和可用宽度计算；不能用芯片的最大额定电流直接当作 PCB 设计电流。
- 普通低压数字板可以把 **1 oz（约 35 µm）外层铜**作为初始评估点；当连续电流、温升、压降或散热要求明显增加时，评估 **2 oz（约 70 µm）或更厚铜**。这两个数是起始选项，不是通用通过标准。
- 内层载流、窄颈、过孔阵列、焊盘瓶颈和铜箔散热必须单独核算；加厚铜不能替代不合理的线宽、过孔或热路径。
- 载流计算优先采用与 IPC-2152 或等效验证方法一致的模型，并记录铜厚、线宽、长度、层别、环境温度和允许温升。需要实物温升时，建议样机测量验证。

### 2. 层数、板厚和叠层

- 简单低速、低功率且回流路径明确的板，可评估 2 层；MCU 混合信号、较多电源或 EMC 要求较高的板，优先评估带连续参考平面的 4 层结构。
- **1.6 mm**可作为常规刚性板的初始机械评估点；薄型、插接挠度、连接器强度和安装结构可能要求约 0.8--1.0 mm 或其他厚度，需按机械约束决定。
- 高速/射频/差分阻抗不能只给层数和板厚建议。必须取得实际介质厚度、介电常数、铜厚、阻焊和目标阻抗后再反算线宽，并在板厂叠层确认后复核。

### 3. 线宽、间距、孔和环宽

- 线宽由载流、压降、阻抗、温升和可布线性共同决定；信号线的线宽不能套用电源线规则。
- 间距由工作电压、瞬态、污染等级、隔离类别、阻抗和串扰目标决定。缺少安规输入时，只输出待确认项，不给爬电/电气间隙结论。
- 孔径、环宽、盲/埋孔和微孔应同时考虑器件引脚、机械强度、纵横比、焊接可靠性和板厂工艺。建议尽量减少没有电气或结构必要性的特殊孔型。
- 最小线宽、间距、孔径和环宽可以作为“通用可制造性筛查”输出，但不能称为板厂能力通过；报告应保留原始单位和测量位置。

### 4. 阻焊、丝印和表面处理

- 焊盘阻焊开窗、阻焊桥和细间距器件应按焊盘图、器件间距和装配方式核对；不能只按丝印框判断可焊性。
- 丝印建议避开焊盘、阻焊开窗、连接器插接区和极性标识；关键位号应在装配后仍可识别。
- HASL、无铅 HASL、ENIG 等表面处理应按焊盘平整度、细间距、接触面、储存寿命和成本目标选择。没有这些需求时只列候选，不指定唯一工艺。

### 5. 机械、拼板和特殊工艺

- 板厚、板框、安装孔、槽孔、金手指、边缘连接器、工艺边和拼板方式应与外壳、连接器、装配方向和测试治具一起核对。
- 槽孔、沉孔、金属化/非金属化孔、边缘电镀等特殊工艺必须单独列出；没有结构图或装配要求时标 `NOT_CHECKED`。
- 需要阻抗、盲埋孔、厚铜、铝基/金属基板或高 Tg 材料时，建议中写清它们对应的电气/热/机械理由，避免为了“更高级”而增加工艺复杂度。

## 不应输出的结论

- 不指定板厂时，不写“可加工”“满足最小线宽/孔径”“价格可接受”或类似承诺。
- 不把 1 oz、1.6 mm、某个固定线宽/间距当作所有板子的默认答案。
- 没有电流、温升、压降、环境温度时，不给铜厚或电源线宽的确定性结论；没有叠层和目标阻抗时，不给阻抗线宽结论。
- 通用建议与板厂核对、Gerber/CAM 审查、样机温升测试分开记录。

## 报告示例

> `NET/VCC+5V` 当前外层铜厚未知，最大连续电流和允许温升未提供。建议先以 1 oz 外层铜作为普通数字板评估点，并按实际电流、线宽、长度和允许温升用 IPC-2152 或等效方法核算；若压降/温升不满足，再评估 2 oz 或加宽/铺铜。状态：`NOT_CHECKED`；复核条件：补充最大电流、长度、环境温度和板厂叠层。
