# 原判据核查与实现能力评估

**日期**：2026-11-07。范围：`docs/` 五份文档、相关提取/校验/几何脚本，以及现有首轮报告的证据边界。没有重新操作 EDA 客户端或修改设计文件。

**结论**：保留“数据交叉校验、逐项证据、未检查必须说明、只读报告”的框架；原清单不能原样用于自动判错。替代判据见 [v2](review-criteria-v2.md)。以下“已确认”指文档/代码行为，不表示某块实际板已有相应缺陷。

## 1. 应修订的判据

| 原条目 | 问题及依据 | 修订方向 |
|---|---|---|
| A-02 自动编号不计 | 原 `validate_netlist.py` 对自动网只统计 `auto_both`，网级比较排除自动网；已复现错误连接返回 0 | 已补共有引脚拓扑比较，缺失/重复成员及特殊映射仍需单独核验 |
| A-03/A-05 网名完全相同 | 别名、自动网名和 pin-to-pad 映射可能不同；反之同名也可能漏成员 | 比较拓扑、映射和覆盖分母，显式处理别名/多焊盘/机械对象/变体 |
| A-04 固定 1 mil | 这是当前项目校准阈值，不是细间距几何正确性的通用证明 | 对每类字段建立量化/变换误差范围；误差接近规则余量则不能给 PASS |
| A-07 连接器映射单调 | 单调并不能证明正确，双排/蛇形/镜像编号也可能合法 | 按精确 MPN 图纸的观察面、接触面、pin 1 和 mating 方向逐脚核验 |
| B-01 NC 集合等于空网焊盘 | 机械孔、未转 PCB 元件、未用脚、多焊盘等破坏一一对应；标 NC 只是设计意图 | 核手册允许条件及真实铜连接，不以集合相等证明电气正确 |
| B-04 无多输出/双向互驱 | I²C 开漏、开集电极、三态共享总线可合法共网 | 核驱动结构、使能时序、上拉和电平，不能只计输出脚数量 |
| B-07 net-tie 必须同网 | 混淆编辑器短接符号逻辑与 PCB 受控跨网连接 | 根据具体库/工具语义和几何连接位置核验 |
| D-01 0 error/warn、全部 S0 | 规则可缺失/禁用/设错；警告影响不同 | 保留原始结果，核规则范围并按后果定级；规则通过不等于功能通过 |
| D-04 连通性已可半自动 | 原脚本跨网并查集；通孔仅考虑 Top/Bottom、无铺铜、缺 pad-pad/via-via 等连接路径 | 已隔离异网接触并报告网对候选，其余模型限制未修，仍不能给整板 PASS |
| D-02/D-03 完整间距复算 | `pcb_clearance.py` 原板框为固定数值（2026-11-07 已改为显式传入/读取）；track-pad 只判采样重叠，没有算正的净距；忽略圆角/挖槽/部分铜对象 | 限定样本与对象范围，不能给整板 clearance PASS |
| E-02/E-03/E-06 固定距离/面积 | 缺少具体器件、拓扑、边沿和回流条件；输入电容—IC—电感三角面积不等于所有变换器的高 di/dt 热环路 | 引用器件布局指南，沿实际电流路径核查；经验数仅作提醒 |
| E-04/E-07 时钟不走外层/晶振包地 | 并非普适规则，需结合参考面、阻抗、寄生电容和厂商建议 | 检查实际回流、串扰、负载与启动裕量，不强制固定层别/包地 |
| E-09 只按耐压定间隙 | 安规还区分工作电压、瞬态、爬电/间隙、绝缘类别、污染、材料与海拔 | 按适用标准和完整输入计算，缺输入不得判定 |
| F-02 每颗有 LCSC 号 | 把特定采购渠道要求写成普遍设计规则；裸铜测试点也未必有采购器件 | MPN/元件规格、装配范围、DNP、渠道料号分开核验 |
| G-01 相位裕度 45° | 常见设计目标不等于所有环路的合格标准 | 绑定项目/厂商目标和模型有效性；核工作点、容差及瞬态 |
| API“权威阶梯” | CAD API/文件读数是同一设计数据库的不同表示，不是实物测量；多份输出可能共享同一错误 | 读数仅证明设计数据，手册/测试/制造输出各证明自己的命题 |

## 2. 已运行的两个最小反例

使用内存 JSON/Protel 文本调用函数。以下先记录修订前实测，再记录修订后结果。最小实现修复已落地，完整几何审核能力尚未实现。

### 2.1 自动网接错仍返回成功

输入 `validate_netlist.main()`：

- 本地网表：`$LOCAL1={U1.1,U2.1}`、`$LOCAL2={U3.1,U4.1}`。
- 参考 Protel 网表：`$1N1={U1.1,U3.1}`、`$1N2={U2.1,U4.1}`。
- 四个引脚都存在，但两个网的连接拓扑已经变了。

修订前输出：`两侧自动编号 4，不同 0`，网级为 `0 个命名网`，函数返回 **0**。修订后增加共有引脚成员分组的拆网/并网检查，此反例返回 **1**；仅修改自动网名、分组不变的对照仍返回 **0**。

### 2.2 异网走线被当作同网连通桥

输入 `pcb_connectivity.main()`（单位 mil）：

```json
{
  "pads": [
    {"x": 0, "y": 0, "layer": 1, "net": "A", "rot": 0, "shape": ["RECT", 4, 4]},
    {"x": 100, "y": 0, "layer": 1, "net": "A", "rot": 0, "shape": ["RECT", 4, 4]}
  ],
  "tracks": [
    {"x1": 0, "y1": 0, "x2": 100, "y2": 0, "layer": 1, "net": "B", "w": 1}
  ],
  "vias": []
}
```

修订前返回 `splits={}` 且没有短路记录。修订后返回 A 网两个同网分量以及候选网对 `('A','B')`；同网走线的对照仍连通且无短路候选。`main()` 返回值由二元组改为 `(splits, net_pads, shorts)`，CLI 已同步；本项目其他脚本只导入几何辅助函数，不受此返回值变化影响。该网对候选基于当前近似模型，不是完整短路诊断。

验证命令（工作区根目录）：

```powershell
python 'projects/epro2-辅助绘制及审核/src/test_review_regressions.py' -v
```

6 个核心回归案例通过：自动网改名、自动网重接、参考成员缺失、空网不能当自动网、同网连通、异网接触；另加 4 个板框传入用例和 3 个 outline path 解析用例（`R`/`L`/`ARC`、裸坐标对），共 13 个。它们验证本轮窄范围修复，不覆盖铺铜、多层过孔或真实板全量检查。

## 3. 对现有首轮报告的影响

`review/信号滤波器成品-V1.0-2026-11-07/report.md` 的原始 API 数值不因本次文档审查自动失效。但是其中 D-04 的“31 个信号网全部同一连通分量”只能按上述脚本能力解释，不能独立证明无开短路；D-02 的间距/板边结果受固定板框和对象覆盖限制。报告已经列出部分铺铜/手册未查项，这是正确做法，应继续保留。

“NC 与空网焊盘对应”只能证明标记和映射一致；“电源脚全部正确”还需精确 MPN/手册；LCSC 号缺失是否影响采购取决于装配渠道。此处提出复审范围，不将既有候选升级为确认设计错误。
