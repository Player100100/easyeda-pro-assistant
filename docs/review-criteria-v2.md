# 原理图与 PCB 审核判据 v2

**日期**：2026-11-07  **状态**：替代 `review-checklist.md` 中与本文冲突的通用阈值和硬性集合判据。本文规定检查方法；项目自己的电气、机械、安规和制造要求仍由设计输入确定。

## 1. 结论先行

现有审核方法的大方向正确：先校验输入数据，网表优先于图面猜测，结论要定位并引用证据，未检查项不能写成通过。但 v1 清单不是一套可直接用于放行或自动判错的标准。若干经验数值被写成普遍阈值，原理图 NC 与 PCB 空网焊盘被要求集合相等；本轮还发现并初步修正了自动网拓扑漏比和 PCB 异网接触未诊断的问题。原有判据/脚本可能造成误报或漏报。

本项目没有发现一个可直接读取 `.epro2` 并可靠判断设计是否合适的成熟通用 skill。当前建议的证据组合是：**EasyEDA 原生 ERC/DRC + 原生网表/焊盘读数 + 按项目要求和器件手册做语义核验 + 有边界声明的离线交叉检查**。KiCad 工具和 agent skill 不能直接作为 `.epro2` 审核器。

逐项缺陷和两个已复现的漏检案例见 [`review-criteria-assessment.md`](review-criteria-assessment.md)。本轮检查的是审核判据和实现能力，没有对某块具体 PCB 重新出完整电气审核结论。

## 2. 判定对象与结果

每条检查先定义它要验证的**要求**，再说明输入数据和判定方法。没有要求来源时，不把某种常见做法当成必须满足的设计规范。

| 结果 | 含义 |
|---|---|
| `PASS` | 要求已明确、输入完整，检查覆盖到要求范围且未发现违反 |
| `FAIL` | 输入可信，且有证据证明设计违反了明确要求或器件/制造限制 |
| `REVIEW` | 发现可疑点、要求未明确，或需要设计者/领域专家确认；不等于故障 |
| `NOT_CHECKED` | 缺少输入、能力或覆盖；不得计入通过 |
| `NOT_APPLICABLE` | 有记录的理由证明该检查不适用 |

每条 finding 至少记录：检查 ID、状态、定位、事实、要求及来源、证据文件/字段/页码、影响、置信度、复核或关闭条件。严重度和置信度分开：严重度表示潜在后果，置信度表示证据强弱。单纯 API 读到一个字段或 DRC 返回空数组，只能证明这项读数为空，不能单独证明设计满足了未配置的要求。

严重度参考：S0 为安全、器件损坏或核心功能失效风险；S1 为重大功能/可靠性风险；S2 为一般功能余量/维护性问题；S3 为提示。候选可以标潜在 S0/S1 以便优先调查，但必须保留 `REVIEW` 和假设条件；**不得仅因后果严重而升级为已确认问题，也不得因尚未确认而自动降成 S2。**

结果针对“检查项 × 对象/工况”，不是整板放行。覆盖率同时列适用总数、实际执行数、可判定数、缺数据数和不适用数；未知分母写未知，不能写 100%。数据冲突只阻断依赖该数据的结论，例如底层坐标待确认不妨碍依据可信网表核算分压。

## 3. 先确认数据和规则，再判设计

1. 固定设计版本、编辑器版本、文件 hash、活动文档和导出时间；原理图、PCB、BOM 与制造输出分别记录版本。
2. 用 EasyEDA 自身网表做原理图重建交叉核验；比较位号/引脚成员关系。自动网名、别名、net-tie、未连接脚和不转 PCB 的元件要单独建模，不能只按网名字符串做等值比较。
3. 核对原理图到 PCB 的位号和引脚/焊盘映射。允许的别名、短接符号、net-tie、NC、机械焊盘和不转 PCB 元件必须逐类解释。未解释的差异是数据/设计问题候选，不自动等同短路或开路。
4. 执行 EasyEDA 原生 ERC 和 PCB DRC，保存完整返回结构、活动板、规则配置、启用层、规则单位、警告/错误数量及工具版本。API 汇总为空时报告为“该次 API 检查返回 0 项”；只有确认规则已配置并覆盖所需对象后，才能称为满足这些规则。
5. 对制造判定记录指定板厂、板层/板厚、铜厚、工艺档、装配条件和能力文件日期。无指定工艺时不套某厂下限。
6. 离线几何只有经过样本校准、单位/坐标系/层映射确认，并与原生读数交叉核验后，才可给 PASS/FAIL。否则输出候选或 `NOT_CHECKED`。

## 4. 原理图与电气连接

### 4.1 原理图 ERC 与图面

- 记录原生 ERC 的错误、警告和规则设置；逐项排除项目允许的电源输入、开集/开漏、总线、三态、未使用单元等合法结构。不能以“ERC 为零”替代逐网络/器件规格审查，也不能把所有 warning 自动视为缺陷。
- 检查引脚类型与实际驱动关系时区分推挽输出、开漏/开集输出、三态、被动引脚、电源脚、模拟输出和允许线与/线或的结构。多个输出在同一网只是待核线索，不能只按 pin type 数量判短路。
- 未连接脚逐引脚检查：明确的 NC 标记、器件手册允许的悬空条件、保留脚要求、上下拉/模式要求分别记录。未标 NC 的输入脚也不必然错误；NC 标记本身也不能证明所有使用条件都满足。
- 连接器脚序、电源极性、信号方向和跨页连接按连接器/对端资料、设计意图和器件手册核对。图面可读性、交叉线歧义、页间标注是单独的人因/维护性检查，不能从网表推出。

### 4.2 原理图—PCB 一致性、NC 与单脚网

- 比较明确的引脚/焊盘成员映射，而非只要求两侧网名相同；记录别名和经批准的 net-tie/短接模型。
- 不要求“原理图 NC 引脚集合 = PCB 空网焊盘集合”。未连接的原理图脚可能不进 PCB；PCB 空网焊盘也可能是机械焊盘、未装器件、保留焊盘或有意悬空。先按位号/脚号/焊盘功能对齐，再与 NC 标记、器件要求和设计意图核验。
- 单焊盘网是**检查线索**，不是自动错误。对测试点、连接器未用脚、预留位置、天线、屏蔽/机械连接、未布线网络等解释其意图，并验证是否满足项目要求。
- “短接符号”和 PCB net-tie 不应混为一类。原理图符号可能表示逻辑上合并；PCB net-tie 通常有意保持不同网名，并在受控几何位置允许连接。分别按器件/库定义、原理图语义、PCB 的 net-tie footprint/DRC 例外验证；不得一律要求两侧被合并为同名网。

### 4.3 器件、电源与接口的必查范围

- **供电**：逐轨检查输入范围、推荐工作范围、最大/瞬态电流、压差/效率、启动与关断顺序、EN/PG/反馈、容差和故障工况。绝对最大额定值是损坏边界，不是正常工作目标。
- **信号兼容**：结合电源域和输入/输出电流核对 VIH/VIL、VOH/VOL、钳位/注入电流、断电回灌、开漏上拉域、上拉 RC 与速率；“网名都是 3V3”不足以证明电平兼容。
- **模拟**：核对共模范围、输出摆幅与负载、输入偏置、GBW、压摆率、稳定性、滤波器容差/噪声/动态范围；电路数值要与目标频带和幅度规格比较，不能仅因接近典型应用而判正确。
- **无源/功率器件**：额定电压/电流/功耗、温度、容差、陶瓷电容 DC bias、ESR/纹波电流、电感饱和与热、MOSFET 栅极驱动与 SOA、保护器件钳位和故障能量按实际工况核验。
- **启动与调试**：BOOT/strap 脚在采样时刻的电平、复位时序、晶振负载、必要供电脚/裸露焊盘、未用模拟单元终止、下载与测试可达性按具体器件核查。
- **封装与变体**：按完整 MPN 核 pin 1、焊盘号、极性、连接器视图/接触面、EP/机械焊盘、DNP、BOM 与实际装配变体。制造商 MPN 是识别依据；LCSC 采购号只有在选择该采购/装配链路时才是必需字段。

DNP 只表示不装配，不会自动删除板上铜和焊盘；仍需验证该变体下的悬空输入、上拉/终端、反馈路径和误装风险。封装多个相同编号焊盘可以合法，但每个物理焊盘仍需独立几何身份和覆盖统计。

### 4.4 C-10 封装与实际器件匹配（2026-11-08 增补）

将型号/封装绑定、引脚定义与极性、物理焊盘清单、尺寸与装配适配分开给结果。以完整 MPN 和封装后缀定位厂商图纸，记录文档版本/页码、库 UUID/来源、定义版本或内容哈希及工程实例。厂商引脚/封装图、推荐焊盘图与实际 PCB 读数各自注明用途；两次读取同一 CAD 数据库不能替代厂商依据。

常规官方库采用基础核对与可追溯历史证据复用；连接器、极性器件、裸露焊盘/特殊封装、关键器件、自建/修改/来源不明或更换过的封装重点复核。只有在型号/封装后缀、符号脚位映射、封装定义、依据版本和相关工艺条件一致，且证据文件仍可取得时，才可复用对应子项；当前实例层别/旋转/映射仍须核对。库来源不明写未知，不能从库名称或供应商料号推定官方来源。

未量测或无匹配图纸的子项记 `NOT_CHECKED`；有明确疑点但证据不足记 `REVIEW`；确认违反具体型号/图纸要求才记 `FAIL`。有完整证据的子项才记 `PASS`，不从网表一致/DRC 零报项推导封装全部通过。尺寸不能统一套经验门限，也不能把器件引脚外形尺寸直接要求等于 PCB 焊盘尺寸；依据匹配的推荐焊盘图、封装公差及项目装配条件判断。详细步骤、覆盖率与记录模板见 [footprint-review.md](footprint-review.md)。

### 4.5 C-11 关键网络供电与电荷预算（2026-11-10 增补）

以「板/电源轨/负载引脚/工况/子项」为判定对象，先列关键网络与工况清单，再核持续供电、瞬态电荷、供给路径压降和重复脉冲恢复。供给能力须对应输入范围、温度、散热、限流与动态响应；负载须说明并发关系、峰值持续时间和重复周期。未知工况不能由网表或芯片典型电流代替。

电荷缺口由同一供电边界的 `I_load(t) − I_source(t)` 积分计算，重复脉冲须计入充电恢复和初始电压。电容预算使用相关电压/温度/容差下的有效容量及允许的电容本体压降，另外核 ESR/ESL、供回电路径压降和负载引脚最低/最高电压；只算 `C × ΔV` 不足以证明瞬态供电通过。跨磁珠、开关或较大阻抗的电容不直接合并；静态额定电流不作为瞬时供给电流。详细公式、证据和适用边界见 [供电与电荷预算审核](power-charge-budget.md)。

四个子项分别报告状态与覆盖；缺参数标 `NOT_CHECKED`，未证实假设支持的筛查结果标 `REVIEW`。已核实工况和有依据的参数/保守界限足以判定时才给 `PASS/FAIL`；余量阈值来自器件/项目要求，不统一设百分比。G-01 按需提供仿真证据，E-02 提供布局/回流依据；当前未实现自动预算检查器，新增规范不表示历史板卡已补审。

## 5. PCB 检查

### 5.1 DRC、几何与连通

- 以 EasyEDA 原生 DRC 和当前项目规则为首要机器证据。检查规则是否启用、覆盖哪些对象/层/网络类，保留 warning；DRC 通过不代表规则设置正确或设计意图正确。
- 离线间距复算需覆盖实际启用层上的铜对象组合（track-track、track-pad、pad-pad、via、zone/pour、板边等），遵循几何形状、线宽/铜厚、净距规则、局部规则、异网/同网语义和单位。只实现了某些组合时，报告该子集，不能笼统写“几何 DRC 通过”。
- 铜到板边、元件本体到板边、阻焊/丝印、孔到板边是不同问题；使用精确板框和对象轮廓。包围盒或中心距适合作为保守筛查，不能冒充精确 clearance。
- 连通性必须按网络、层、对象铜形状、镀孔属性、过孔跨层范围和已填充铜区的实际连接计算。可建包含所有铜接触的物理图，逐分量检查异网短路，再核各逻辑网的连接需求；也可建同网图并独立检查所有异网接触。不能只把异网并到同一个 DSU 而遗漏短路诊断。铺铜未校准或未包含时，依赖这些铜区的连接不得报 PASS。
- `src/pcb_connectivity.py` 已改为同网合并、异网接触单独报告为网对候选；但走线—焊盘按采样判断，过孔层范围固定假设，铺铜未参与，未知形状使用近似，仍不能作为 D-04 通过证据。网对候选还缺具体接触对象定位、net-tie 例外与精确短路验证。`src/pcb_clearance.py` 只覆盖部分几何组合，板框需从 `board_size`/`outline` 或 `--pcb`/`--board` 显式提供，且对走线—焊盘只检测重叠；不能据此宣称完整 DRC 或 DFM 通过。
- `validate_netlist.py` 原先跳过自动网拓扑，本轮已补共有引脚的拆网/并网比较，并拒绝参考网表出现但提取侧缺失的引脚、空网误当自动网。仍需逐项解释提取侧独有引脚、重复键/多实例/多板与别名；历史“0 命名差异”不等于用新版重跑后的全网一致。
- 当前清单中的 A-04 `≤1 mil` 是工程对账容差，不是通用标准。先用同一对象/单位/变换标定误差；容差应据数据精度和校准结果设定。超差时降级几何结论并调查坐标，不自动判板错。
- 单位由字段定义/受控接口或校准样本明确。规则单位与显示单位冲突时记录冲突，使用可信 API 或人工确认的工艺值；不能因为“某个数按 mil 才常见”就反推单位并给出通过结论。

### 5.2 设计意图与制造

- 去耦器件数量、容值、距离和过孔位置应由器件手册/参考设计、电流瞬态、封装电源/地引脚、回流路径和 PCB 层叠确定。不得把“5 mm/8 mm/3 mm”写成适用所有 IC 的 pass/fail 阈值；缺少器件依据时只能标为筛查提醒。
- 开关电源环路面积、SW 节点面积、反馈走线、热焊盘/过孔和地回路，按具体控制器的数据手册或厂商布局指南逐项定位。通用面积数字只能作为明确来源的经验告警，不能直接判错误。
- 晶振、差分对、等长、阻抗和高速回流要按具体器件接口规范、数据速率/边沿、堆叠与受控阻抗要求检查。没有叠层和目标阻抗时写 `NOT_CHECKED`，不以“少过孔”或“时钟不走外层”作普适规则。
- ESD/浪涌/滤波器件是否需要、选型与摆放距离，取决于接口暴露、标准等级、线缆、接地/机壳路径和器件布局指南。不可将“连接器 25 mm 内必须有 ESD”设为通用判据。
- 爬电距离、电气间隙、隔离槽和污染等级必须绑定适用安全标准、工作电压、过电压类别、污染等级、材料组/CTI、海拔和绝缘类别；缺任一关键输入时标 `NOT_CHECKED`，不猜阈值。
- 可制造性数值引用当前所选板厂的受控能力页/报价工艺；IPC/IEC/地区法规须标出标准编号、版本和适用条款。库存/可采购性与设计电气正确性分开报告。
- 制造输出需核 Gerber/钻孔的实际层、外形/槽孔、镜像、阻焊开窗、钢网、丝印与坐标/BOM 版本。IPC-D-356A 可交叉核对测试网表，但从同一 CAD 产生的两个网表一致不证明 Gerber 实际铜几何一致；需要 CAM 提取网表或明确的制造文件几何核验。

### 5.3 仿真

- 仿真判据必须在运行前写明目标、测试条件、输入范围、容差、负载、温度/工艺角、模型版本和模型来源。
- “相位裕度 ≥45°”不是通用电源通过线。它可能是特定设计规范或应用指南要求；同时要验证环路注入点、稳定工作点、负载/输入/输出电容范围与模型有效性。没有这些信息时不下稳定性结论。
- 仿真不能证明 ERC/网表/封装映射/DRC 正确；SPICE 模型不代表布局寄生、EMC 合规或器件绝对最大额定值已覆盖。
